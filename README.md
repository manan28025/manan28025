My interests are aligned with data analytics, business intelligence, predictive modelling and data storytelling.

- Finalist at Flipkart Grid 7.0 and 5th place at the Honeywell Hackspace Hackathon

- Mainly building end-to-end analytics projects: SQL pipelines, ML models and Power BI dashboards
